# 🗡️ 레지스탕스 아발론: 온라인 (The Resistance: Avalon Online) - v2.1 (Security Update)

오프라인 마피아 류 보드게임인 **레지스탕스 아발론(The Resistance: Avalon)** 을 브라우저 환경에서 5~10인의 플레이어가 실시간으로 즐길 수 있도록 구현한 웹 애플리케이션입니다. 

기존의 Vanilla JS(단일 파일) 구조에서 벗어나 **Vite 빌드 도구를 활용한 모듈형 아키텍처**로 재탄생했습니다. 별도의 서버 구축 없이 Firebase Realtime Database를 활용하여 플레이어 간의 상태 동기화와 게임 로직을 순수 클라이언트 환경에서 처리합니다.

## 🎲 주요 업데이트 내역 (v2.0 리엔지니어링)

### 🚀 모듈화 및 아키텍처 개편 (Vite 도입)
* 방대한 1개의 파일로 묶여있던 코드(index.html)를 역할에 따라 완벽하게 모듈 분리(MVC 패턴 차용).
* Vite를 도입하여 개발 편의성, 빠른 HMR(Hot Module Replacement), 그리고 프로덕션 빌드의 최적화를 달성했습니다.

### 🛡️ 완벽한 종단간 암호화(E2EE) 및 방장 인계 시스템
* **F12 컨닝 원천 차단:** 서버리스(무로그인) 환경의 취약점을 극복하기 위해 Web Crypto API를 도입했습니다. 플레이어의 직업과 투표(성공/실패) 데이터가 완벽히 암호화되어 파이어베이스에 저장되므로, 게임 도중 개발자 도구를 통한 악의적인 해킹이 불가능합니다.
* **방장 인계(Host Transfer) 호환:** 강력한 암호화를 유지하면서도 방장이 네트워크 문제로 튕겼을 때, 다른 플레이어가 방장을 인계받아 암호화된 게임 기록을 100% 안전하게 복구할 수 있는 독자적인 '방 전용 공용 키(Room Key)' 시스템을 구축했습니다.

### 🎨 디자인 및 UI/UX 완전 개편
* 모던 웹 디자인 트렌드를 반영한 **다크 템플릿(Glassmorphism, 미세 애니메이션, 세련된 색상 조합)** 적용.
* 버튼, 입력창, 대시보드가 모바일 환경에서도 전혀 스크롤이나 레이아웃 깨짐 없이 쾌적하게 보이도록 반응형 UI 구현.
* **상태 현황 보드 강화:** 원정대장 로테이션을 시각적으로 가장 앞에 오도록 표시하고, 라운드별 실패 기준 등 게임 플레이에 꼭 필요한 정보량을 콤팩트하게 제공합니다.

### 🛠️ 로직 고도화 및 예외 처리
* **비밀 원정 수행 시**, 선 진영 플레이어는 오직 '성공' 카드만 낼 수 있도록 강제하여 게임 규칙 상의 치명적인 실수를 방지.
* 어새신의 암살 타겟에서 처음부터 같은 악 진영은 배제되도록 필터링 처리.
* 파이어베이스 쓰기 충돌 방지 및 네트워크 안정성 강화.

## 📌 주요 기능 (Key Features)

### 1. 실시간 멀티플레이 로비 및 방 관리
* **방 생성 및 입장:** 4자리 난수 코드를 통한 프라이빗 룸 생성.
* **가비지 컬렉션 (데이터 정리):** 클라이언트 접속 시 24시간이 경과한 오래된 방 데이터를 자동으로 삭제하여 DB 용량 최적화.

### 2. 아발론 핵심 룰 완벽 구현
* **가변 인원 지원:** 5인부터 10인까지 인원수에 따른 요구 원정대원 수 및 진영 비율 완벽 적용.
* **직관적인 직업(역할) 배정:** 멀린, 퍼시벌, 아서왕의 신하(선 진영) / 어새신, 모르가나, 모드레드, 오베론, 모드레드의 수하(악 진영) 완벽 한글화 적용.
* **자동화된 게임 페이즈 전환:** 원정대장 순환 ➡️ 원정대 지목 ➡️ 팀 찬반 투표 ➡️ 비밀 원정 수행(성공/실패).

### 3. 암살자 단계 및 마크다운 게임 기록
* 3번의 원정 성공 시 악 진영에게 역전 기회를 제공하는 **암살자 단계** 구현.
* 게임 종료 후 게임의 진행 내역을 마크다운 형태의 **'게임 기록'**으로 생성.
* **보안 기록 보관소:** 관리자 비밀번호를 입력해야만 접근 가능한 과거 기록 보관소(History Vault) 기능을 통해 이전 게임들의 결과와 마크다운 기록을 안전하게 열람 및 관리 가능.

## 🚀 로컬 실행 및 배포 방법

### 1. 패키지 설치 및 환경 설정
본 프로젝트는 Vite를 사용하므로 Node.js가 필요합니다.
```bash
npm install
```

### 2. Firebase 연동
`/src/api/firebaseApp.js` 파일 내의 `firebaseConfig` 객체를 본인의 Firebase 프로젝트 설정으로 변경해주세요.

### 3. 로컬 테스트 실행
```bash
npm run dev
```

### 4. 프로덕션 빌드
```bash
npm run build
```
빌드된 정적 파일들은 `dist/` 디렉토리에 생성되며, 이를 GitHub Pages, Vercel, Netlify 등을 통해 쉽게 무료 호스팅 할 수 있습니다.
